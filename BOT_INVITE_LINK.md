2. Select your application (Client ID: 1452733157701976106)
3. Go to "OAuth2" > "URL Generator"
4. Select scopes:
   - ✅ `bot`
   - ✅ `applications.commands`
5. Select bot permissions:
   - ✅ Manage Roles
   - ✅ Send Messages
   - ✅ Read Message History

6. Copy the generated URL
